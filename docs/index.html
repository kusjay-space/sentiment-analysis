📋 Abstract

Pipeline NLP untuk mengklasifikasi review teks menjadi tiga kelas: POSITIVE, NEUTRAL, atau NEGATIVE. Pendekatan bertahap: baseline TF-IDF + Logistic Regression (70.2% validation) lalu fine-tune DistilBERT (75.1% test, +4.9 poin). Model juga diuji pada review asli Play Store di luar dataset training untuk memvalidasi generalisasi: 74.6% pada review berbahasa Inggris (selisih 0.5 poin dari test set akademik — bukti tidak overfit), dan 57.5% pada review berbahasa Indonesia dengan 69% prediksi ber-confidence rendah (model menandai ketidakpastiannya sendiri).

🔬 Metodologi

  1. Data preparation. Load dataset, mapping bintang ke 3 kelas sentimen, EDA (distribusi label, panjang teks, sampel).
  2. Baseline. TF-IDF (sublinear TF, 100k features, bigram) + Logistic Regression dengan class_weight='balanced'. Sweep 4 konfigurasi hyperparameter untuk menemukan ceiling.
  3. Fine-tuning. DistilBERT base uncased, subsample stratified 30k (12k/6k/12k, seed 42), max_len 128, batch 32, lr 2e-5, 2 epoch, fp16 di GPU T4.
  4. Evaluasi. Seleksi model di validation split; angka final dilaporkan dari test split yang disentuh tepat sekali. Metrik: accuracy, F1-macro, F1 per kelas, confusion matrix.
  5. Inference. 10 sampel unseen dari test split (seed 42) → teks, label asli, prediksi, confidence.
  6. Validasi data nyata. Scraping review asli Play Store (EN & ID) untuk menguji generalisasi di luar distribusi training.

🌍 Validasi Data Nyata (Play Store)

Test set akademik bisa menipu — model bisa menghafal pola dataset. Karena itu model diuji pada review asli hasil scraping Play Store, di luar distribusi training. Ground truth = star rating dengan mapping yang sama.

TestDatanAccuracyF1-macroConf < 0.5
Test set akademikAmazon Reviews (test)5.000 75.1%0.687—
Real-world EnglishPlay Store US (Spotify, Instagram)67 74.6%0.59310%
Real-world IndonesianPlay Store ID (Gojek, Tokopedia)80 57.5%0.36469%

1. English generalizes. Selisih 75.1% (akademik) vs 74.6% (nyata) hanya 0.5 poin — bukti model tidak overfit dan benar-benar belajar sinyal sentimen, bukan menghafal dataset.

2. Indonesia di luar domain. Model dilatih hanya pada teks Inggris; tokenizer memecah kata Indonesia menjadi 2–4 subword tanpa makna (contoh: mengecewakan → meng/##ece/##wa/##kan). Akurasi turun ke 57.5% dengan bias ke NEGATIVE (60 dari 80 prediksi).

3. Model menandai ketidakpastiannya. Di data Indonesia, 69% prediksi punya confidence < 0.5, versus hanya 10% di data English. Model tidak salah tebak dengan yakin — perilaku yang diinginkan untuk sistem produksi (bisa di-flag untuk review manusia).

4. Noise di data nyata. Sebagian review Play Store US ternyata berbahasa Portugis, dan sebagian label bintang tidak konsisten dengan teksnya. Ceiling akurasi pada data nyata memang lebih rendah dari benchmark akademik.

Implikasi produksi: untuk feedback pengguna Indonesia diperlukan model berbahasa Indonesia (IndoBERT / XLM-R) yang dilatih pada korpus Indonesia — di luar scope assessment ini.

⚠️ Challenges & Limitations

  • Baseline TF-IDF mentok di ~70% (sweep: bigram/trigram/char n-gram semuanya < 71%) — bottleneck kelas NEUTRAL (F1 0.47)
  • DistilBERT lebih baik (75.1%) tapi target 85% tidak tercapai — training hanya 2 epoch di subset 30k; NEUTRAL tetap terlemah (F1 0.40)
  • Review netral (bintang 3) secara inheren ambigu — bahkan model kontekstual kesulitan; perbaikan: train full 200k, 3-4 epoch, atau focal loss
  • Panjang teks > 128 token dipotong, bisa kehilangan konteks (1.7% review)
  • Dataset hanya bahasa Inggris, tidak generalizable ke bahasa lain
  • Kelas NEUTRAL minoritas (rasio 2:1:2) — F1 per kelas dilaporkan
