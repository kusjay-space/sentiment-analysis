📋 Abstract

Pipeline NLP yang mengklasifikasikan review pengguna menjadi tiga kelas: POSITIVE, NEUTRAL, dan NEGATIVE. Pendekatan bertahap: baseline TF-IDF + Logistic Regression (70.2% validation), lalu fine-tune DistilBERT (75.1% test, +4.9 poin).

Untuk menguji apakah model benar-benar belajar sinyal sentimen — bukan menghafal dataset — model diuji pada review asli hasil scraping Play Store: 74.6% pada review berbahasa Inggris (selisih hanya 0.5 poin dari test set akademik), dan 57.5% pada review berbahasa Indonesia dengan 69% prediksi ber-confidence rendah, karena model memang hanya dilatih pada teks Inggris.

📚 Dataset

Sumber: HuggingFace — SetFit/amazon_reviews_multi_en (salah satu platform yang direkomendasikan brief, selain Kaggle dan Roboflow).

Ukuran split

Split Tersedia Dipakai Keterangan
Train 200.000 30.000 subsample stratified (12k NEG / 6k NEU / 12k POS), seed 42
Validation 5.000 5.000 untuk seleksi model & hyperparameter
Test 5.000 5.000 disentuh tepat sekali untuk angka final
Kenapa hanya 30.000 dari 200.000? Model dilatih pada subsample agar fine-tuning selesai dalam ~30 menit di GPU T4 (kuota Colab gratis) dan tetap cukup untuk proof-of-concept sesuai brief. Dataset penuh tetap didokumentasikan agar hasil dapat direproduksi.

🔬 Metodologi

  1. Data preparation. Load dataset, mapping 5 bintang ke 3 kelas sentimen, lalu EDA: distribusi label, distribusi panjang teks, dan inspeksi sampel per kelas.
  2. Baseline. TF-IDF (sublinear TF, 100k fitur, bigram) + Logistic Regression dengan class_weight='balanced'. Empat konfigurasi hyperparameter disapu untuk menemukan ceiling pendekatan klasik.
  3. Fine-tuning. DistilBERT base uncased, subsample stratified 30k, max_len=128, batch 32, learning rate 2e-5, 2 epoch, fp16 pada GPU T4.
  4. Disiplin split. Seleksi model dan hyperparameter hanya di validation. Angka final dilaporkan dari test yang disentuh tepat sekali, sehingga tidak ada kebocoran data ke proses seleksi.
  5. Evaluasi. Accuracy, F1-macro, F1-weighted, F1 per kelas, dan confusion matrix. F1-macro menjadi metrik pendamping utama karena kelas tidak seimbang.
  6. Inference. 10 sampel unseen dari test split (seed 42) → teks, label asli, prediksi, dan confidence.
  7. Validasi data nyata. Scraping review asli Play Store (Inggris & Indonesia) untuk menguji generalisasi di luar distribusi training.

🌍 Validasi Data Nyata (Play Store)

Test set akademik bisa menipu: model berpotensi menghafal pola dataset. Karena itu model diuji pada review asli hasil scraping Play Store menggunakan google-play-scraper, di luar distribusi training. Ground truth = star rating dengan mapping yang sama seperti training.

Test Data n Accuracy F1-macro Conf < 0.5
Test set akademik Amazon Reviews (test split) 5.000 75.1% 0.687 —
Real-world English Play Store US (Spotify, Instagram) 67 74.6% 0.593 10%
Real-world Indonesian Play Store ID (Gojek, Tokopedia) 80 57.5% 0.364 69%

Temuan

  1. Bahasa Inggris ter-generalisasi. Selisih 75.1% (akademik) vs 74.6% (nyata) hanya 0.5 poin — bukti model belajar sinyal sentimen, bukan menghafal dataset.
  2. Bahasa Indonesia di luar domain. Model dilatih hanya pada teks Inggris; tokenizer memecah kata Indonesia menjadi 2–4 subword tanpa makna (contoh: mengecewakan → meng · ##ece · ##wa · ##kan). Akurasi turun ke 57.5% dengan bias ke NEGATIVE (60 dari 80 prediksi).
  3. Model menandai ketidakpastiannya. Di data Indonesia, 69% prediksi punya confidence < 0.5 — versus hanya 10% di data Inggris. Model tidak salah tebak dengan yakin; perilaku ini justru diinginkan di produksi karena prediksi berconfidence rendah bisa di-flag untuk review manusia.
  4. Noise pada data nyata. Sebagian review Play Store US ternyata berbahasa Portugis, dan sebagian label bintang tidak konsisten dengan teksnya (teks negatif diberi 5 bintang). Ceiling akurasi pada data nyata memang lebih rendah dari benchmark akademik.
Implikasi produksi: untuk feedback pengguna berbahasa Indonesia diperlukan model berbahasa Indonesia (IndoBERT / XLM-R) yang dilatih pada korpus Indonesia. Ini di luar scope assessment ini dan dicatat sebagai future work.

⚠️ Limitasi & Pelajaran

  • Target 85% tidak tercapai (realisasi 75.1%). Penyebab: training hanya 2 epoch pada 30k sampel, dan NEUTRAL secara inheren ambigu. Angka dilaporkan apa adanya, bukan dioptimalkan pada test set.
  • NEUTRAL adalah bottleneck utama (F1 0.403). Bintang 3 mencakup review campuran — "bagus tapi mahal" — sehingga batas antar kelas kabur bahkan bagi manusia.
  • Baseline TF-IDF mentok di ~70%. Sapuan hyperparameter (bigram, trigram, char n-gram, 510k fitur, C besar) semuanya < 71%, mengonfirmasi bahwa pendekatan tanpa konteks punya ceiling di dataset ini.
  • Eksperimen lanjutan tidak dipakai. DistilBERT pada 200k penuh + 3 epoch + class weight NEUTRAL×2 menaikkan F1 NEUTRAL (0.398 → 0.531) tetapi menurunkan accuracy (74.9% → 71.2%) karena NEGATIVE tergerus. Trade-off tidak menguntungkan, sehingga model 30k dipertahankan.
  • Hanya bahasa Inggris. Terbukti dari uji data nyata: 57.5% pada review Indonesia dengan 69% confidence rendah.
  • Pemotongan teks. 1.7% review melebihi 128 token sehingga konteksnya terpotong.
